# 🤖 د اریان د اوږدو نمبرونو بوټ کمنډونه

بله ورځ یا په هر نوي موبایل کې د بوټ د چالانولو لپاره دا لاندې ۳ کمنډونه په ترتیب جلا جلا په ترموکس کې ووهئ:

### ۱. د پخواني هر څه پاکول:
cd ~ && rm -rf alibot alibot.py

### ۲. له ګیټ هب څخه د پوره پروژې راکښل (وی پي این روښانه کړئ):
git clone https://https://github.com/ariansab212-oss/alibot.git

### ۳. د فولډر ننه ننوتل او د بوټ چالانول:
cd alibot && python alibot.py
